# Espaçamento

## Padding Horizontal (por Breakpoint)

| Desktop | Tablet (max-md) | Mobile (max-sm) | Contexto |
|---------|-----------------|-----------------|----------|
| `px-12` (48px) | `px-8` (32px) | `px-3` (12px) | Seções principais |
| `px-16` (64px) | — | `px-6` (24px) | CTA container |
| `px-20` (80px) | — | — | CTA desktop |

| Valor | Uso |
